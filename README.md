# 综合性 AI 运营智能体

面向客户的综合性 AI 智能体 Web 应用:既能科学地分析客户需求(5W2H 方法论 + 公开数据调研),
又能**直接完成实际任务**——撰写发言稿、制作主题 PPT、撰写报告方案、通知公告等,
并生成 **Word / PPT / Excel / PDF** 各类交付文件。

## 核心特性

- **需求分析**:单轮核心提问(≤3 问)→ 结构化需求文档(5W2H + 功能/非功能 + 约束 + 预算 + 周期
  + 优先级 + 风险)→ 确认卡(可修改)→ 选择导出文件(Word 报告/PPT 演示/Excel 表格/PDF 文档)
- **严谨的数据调研**:内置调研模块直接检索公开网页(政府数据/行业报告等),**零第三方搜索 API**;
  每条引用数据绑定来源 URL 与检索日期,**严禁编造数据与来源**;检索不到则显式标注假设
- **通用任务引擎**:识别客户的创作请求(发言稿/主题PPT/报告方案/通知公告),补充必要信息(≤2 问)后
  直接生成交付文件;报告/PPT 类任务自动附公开数据调研,数据处标注引用
- **主动建议**:需求确认后主动告知客户可完成的延伸任务;欢迎页展示全部能力卡片
- **会话持久化**:重启服务后历史会话与文件记录自动恢复

## 快速开始

### 1. 环境要求

- Windows(依赖自带中文字体:微软雅黑/宋体/黑体)
- Python 3.12+(已在 3.14 验证)

### 2. 安装依赖

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

### 3. 配置

复制 `.env.example` 为 `.env`,填入 DeepSeek API Key(唯一需要的密钥,调研模块不需要任何搜索 API):

```
DEEPSEEK_API_KEY=sk-你的key
```

### 4. 启动

```bash
.venv\Scripts\python run.py
```

浏览器打开 http://127.0.0.1:8000

### 5. 使用流程

1. 新建会话,用自然语言描述需求(如"我想做一个员工考勤系统,约 50 人使用")
2. 逐轮回答智能体的澄清问题
3. 自动数据调研(检索已公布的同类数据,进度实时展示)
4. 查看需求确认卡(摘要 + 数据来源 + 完整 JSON),可确认或提出修改
5. 确认后点击按钮生成 Word/PPT/Excel/PDF,在线下载

生成文件保存在 `output/{会话id}/` 目录。

## 目录结构

```
app/
├── main.py            # FastAPI 入口
├── config.py          # 配置(.env)
├── agent/             # 状态机编排(clarify→research→confirm→done)、澄清规则、定稿
├── llm/               # DeepSeek 客户端(JSON 三重防线)、全部提示词
├── research/          # 公开数据调研:权威源注册表、搜索抓取、数据点提取
├── files/             # 文件生成流水线:注册表 + 四类渲染器
├── api/               # 会话 CRUD、SSE 流端点、文件生成/下载
├── store/             # 会话存储(内存 + JSON 持久化)
├── models/            # 需求文档 Schema、四类文件 IR
└── utils/             # 中文字体、文本处理
static/                # 前端(vanilla JS 单页,无构建)
scripts/test_renderers.py  # 渲染器自检(手写 fixture,不含 LLM)
```

## 已知限制与说明

- **单机运行**:会话存储在内存 + `data/sessions.json`,服务固定单 worker 启动;
  **面向客户公网部署前必须增加用户鉴权层**(v1 无账号体系,仅限本机使用)
- **公开数据检索为尽力而为**:不依赖第三方搜索 API,通过公开搜索页抓取;
  个别站点改版或反爬会导致该次检索为空(自动降级并明示,绝不虚构数据);
  商业部署建议接入正式搜索服务(如博查/Tavily)以获得稳定检索能力
- **调研与文件生成耗时**:单次调研约 20~40 秒,单个文件生成约 15~60 秒
- **PDF 依赖 Windows 中文字体**:`C:\Windows\Fonts` 下的微软雅黑/宋体/黑体,字体子集嵌入,交付文件可移植
